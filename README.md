# React Shop

A responsive e-commerce website built with React, Vite and Sanity.

## 🛠️ Technologies

- React
- JavaScript
- Vite
- Sanity
- HTML5
- CSS3

## ✨ Features

- Product browsing
- Product information
- E-commerce style interface
- Content management with Sanity
- Responsive design
- Reusable React components

## 📚 What I Learned

This project helped me practice:

- Building reusable React components
- Managing application structure with React
- Working with Vite
- Connecting a React application to Sanity
- Creating responsive layouts
- Organizing CSS separately from components

## 🎯 Project Purpose

This project was created as part of my Front-End Development training to practice building a complete e-commerce-style application with React.
